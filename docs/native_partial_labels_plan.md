# Idea 3 native VCG training with partial region annotations

Test whether location mentions in additional measured Frank XYZ recordings contribute useful supervision to the original six-class patient classifier. The target cohort stays at 164 patients, 391 recordings and 55,863 beats, with all ten frozen folds and seeds 42, 123 and 2026. The validated native study used extra waveforms without region supervision. [Backlog](RESEARCH_BACKLOG.md) · [Native pilot findings](vcg_pretraining_pilots_findings.md)

Use the source bank generated by the original native audit and confirm its provenance again. Select outside-target patients whose eligible recordings consistently contain one of the declared original acute infarction location codes. Rebuild all selected patients' crops from the original source and require exact equality to the private bank. The annotations are original header mentions. Review here means verifying source text and consistency, without new clinical adjudication. Source location codes stay outside the target six classes.

The shared auxiliary vocabulary is anterior, inferior, lateral and septal, as in the previous territory study. Source head loss uses only explicitly mentioned tags in this vocabulary. Unmentioned tags contribute zero loss. A posterior-only patient has no supported tag and is counted in the audit without entering supervised training. Very sparse tags and recurring inferior/posterolateral cases limit what can transfer.

## Four matched arms

- **Scratch.** Target six-class CE with an unused region head.
- **Target descriptors.** Target CE plus 0.2 times the existing class-name derived descriptor loss.
- **Shuffled source mentions.** Target descriptors plus a 0.2 weighted source positive-only loss. Permute source patient tag vectors among the same patients, without assigning any vector back to its own patient. Preserve marginal tag counts and minimize identical vectors under the permutation.
- **True source mentions.** Same target and source samples as shuffled, with each original positive vector.

The target auxiliary BCE is the same class-name encoding convention as the prior study. The source objective is averaged over each sample's observed positive tags, then across samples, so extra tags do not automatically give a patient more weight. Every source sample supplies measured XYZ only and has no six-way target loss. The true and shuffled arms have matched source exposure, optimizer updates, architecture, dropout, losses and initialization. Tag dominance can leave identical vectors after shuffling and will be reported. No score chooses the permutation.

The fixed target recipe is eight epochs, 2,048 target beat presentations per epoch, batch 128 and the same target class/patient balanced draws within each fold and seed. In both source arms each update draws two beats from each of the 13 eligible patients, for 26 total. This keeps the source tag counts matched at every update. Target-only normalization applies to both target and source inputs. All settings are fixed across folds, with zero outer-test training or stopping feedback. Only the original six-way head is used at inference.

Primary contrast is true source mentions versus shuffled source mentions. Comparisons against target descriptors and scratch show whether the method adds value over target-only fitting. Report all 120 outer fits and all seeds, equal-probability ensemble patient macro F1, mean member metrics, class results and paired descriptive intervals. A fresh process verifies training memberships and sample-plan hashes, restores every model and replays held-out inference. This is development evidence at one fixed budget.
