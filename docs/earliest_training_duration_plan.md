# Training duration for earliest-record measured-XYZ localization

This experiment tests whether more optimization steps improve the supervised baseline from the completed later-recording study. Preserve the same model, original beat cache, earliest recording and deterministic fallback policy, patient/class-balanced sampling with replacement, seeds 42, 123 and 2026, ten fixed outer patient folds, batch size 128, 2,048 beats per epoch, fixed AdamW learning rate, and ordinary beat cross-entropy. Checkpoints at 8, 16 and 32 epochs represent 128, 256 and 512 optimizer updates. Save all three along each continuous trajectory. Run inference after saving the trajectory so intermediate evaluations cannot change training randomness or stopping. [Source model](../results/neural_later_recording_distillation_v1/complete/REPORT.md)

Within each outer-training set and seed, use three stratified patient folds with a fixed split seed derived from the outer fold. Inner training includes the same fallback rule as the outer training. At each duration, pool the inner held-out patient probabilities over eligible dated patients and compute six-class patient macro F1. Select the highest scoring duration, with exact ties favoring fewer updates. Choose before fitting or evaluating the corresponding outer model. From a fresh outer-training trajectory, use the selected checkpoint for the primary paired comparison against fixed 8 epochs on the same 145 date-eligible patients. Report the fixed 16- and 32-epoch arms and the all-patient fallback cohort as descriptive sensitivities. The analysis reports losses at each checkpoint, per-class F1 and 5,000 descriptive class-stratified paired bootstrap draws. Longer duration earns consideration if it improves held-out macro F1 with evidence of MI-subtype gains.

Require the verified source receipts and reproduce all 30 original eight-epoch probability blocks within the source replay tolerance, with exact pooled patient decisions. Rebuild all split, normalization and sampled-row audits and restore every checkpoint before publishing. The full inventory contains 90 inner and 30 outer trajectories and 360 checkpoints. The smoke run uses the first outer-training partition only, on one seed and checkpoints at 1, 2 and 3 epochs. Private checkpoints and probability blocks remain ignored. PTB remains development data.
