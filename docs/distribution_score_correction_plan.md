# Frozen baseline score correction

The prior learned distribution study appended 144 summary columns and refitted the original convolution coefficients. Its strongest added-feature ensemble reached 0.580895 versus the matched 0.584266 baseline. This follow-up asks whether beat variation is complementary when it can only add a regularized correction to the original scores. The primary contrast is the learned quantile correction versus the frozen convolution baseline.

Use the existing independently replayed convolution and learned feature banks. Compare mean/spread and empirical quantiles from each family with the same 144-column width, fit rule and search budget. Both banks must reproduce the same standardized 3,584-column baseline for every patient partition. The source manifests anchor the cache, membership and numerical hash checks. Learned encoders retain their original inner-validation early stopping. Upstream reports provide waveform replay evidence. The follow-up reads their cached features and restores the original baseline.

For each partition, subtract the class-balanced training mean from the auxiliary columns. Fit an additive ridge correction without an intercept to the residual between the ±1 class target and the frozen baseline decision scores on training patients. The loss uses class-balanced sample weights. The positive penalty is the weighted centered feature energy (the trace of the weighted Gram matrix) times 1.0 or 0.1. The first candidate returns the original prediction exactly. Training residuals are in-sample with respect to the frozen baseline, so a tightly fitted baseline can leave little residual signal.

For each outer fold and seed, use the three inner folds to pick the baseline alpha from the original [1, 100] candidates by mean patient macro F1. At that shared baseline alpha, each branch selects off, strong or weaker regularization from the same inner scores. Ties use the order listed. Restore the original outer baseline at the selected alpha and fit each selected correction to outer-training patients. Aggregate held-out patient predictions across all ten folds and all three declared seeds. Compare equal probability ensembles and retain member macro F1 separately. Paired patient intervals use shared class-stratified resampling of fixed predictions.

The declared budget is 120 matched partition/seed contexts, 210 baseline model restores, 720 active inner correction fits and up to 120 active outer fits. Report realized outer counts, including disabled branches. The independent report runs in a fresh interpreter, rechecks source hashes, reconstructs all corrections and compares the saved coefficients, predictions and inner selections. Private patient data and fitted states live under the ignored review directory. Published outputs are aggregate metrics and verification hashes.

Run the real inner-only smoke with `.venv/bin/python scripts/run_distribution_score_correction.py --smoke`. Run fitting and independent replay with `.venv/bin/python scripts/run_distribution_score_correction.py`. Read the completed report at `results/distribution_score_correction_v1/complete/REPORT.md`. The original cohort contains 164 patients, 391 recordings and 55,863 beats, with measured Frank XYZ as the input. This comparison uses the established development cohort. Prior reports document the original study scopes and their limits.
