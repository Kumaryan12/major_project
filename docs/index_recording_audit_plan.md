# Earliest recorded examination sensitivity on PTB

This diagnostic tests how much the frozen measured Frank XYZ ResNet depends on having all recorded examinations available. It reuses the published fixed-eight-epoch scratch checkpoint predictions from all ten original patient folds and all three seeds. There are zero new fits. The primary comparison is one earliest dated recording versus the all-beat reference on exactly the same patients. The results describe archival ECG dates and cannot establish performance at hospital presentation. [Source result](../results/neural_vcg_native_pretraining_v1/complete/REPORT.md) · [PTB database](https://physionet.org/content/ptbdb/1.0.0/)

Read only the `ECG date` header field as day/month/year. The preceding metadata screen found 269 records with first field above 12 and none with second field above 12. Treat missing, duplicate or malformed date fields as unusable. Eligibility requires a valid date for every retained recording and exactly one record on the earliest date. Establish eligibility using record membership and dates before loading predictions or evaluating labels. Report every class's coverage and identify aggregate counts for missing dates and earliest-date ties. No individual dates or predictions are published.

- Primary comparison uses only the subset meeting the date rule. Average all beats from the chosen record within a seed, then average the three seed vectors and take one six-class argmax. The matched baseline averages every available beat of the same patients. The primary contrast is earliest minus all beats.
- Repeat the primary contrast for eligible patients with multiple recordings to assess change when the input can differ. This subgroup is descriptive.
- On all 164 patients, retain the published reference, evaluate equal-record averaging of all available recordings, and evaluate a one-record sensitivity policy. Under that policy take the unique earliest date where available, the lexicographically first same-day record for an earliest-date tie, and the lexicographically first retained record when any date is unusable. The fallback measures single-record sensitivity with full coverage.
- Report ensemble and every member's patient macro F1, class support, accuracy and class precision/recall/F1. Use 5,000 paired class-stratified bootstrap draws with seed 42 for the planned contrasts. The intervals condition on the saved predictions and observed class counts. Publish all declared comparisons.

A primary point loss of at least .02 macro F1 plus an interval below zero would support using earliest-record scoring as an explicit secondary endpoint in the next waveform study. If the interval crosses zero, preserve it as a descriptive endpoint and interpret the direction alongside eligible multi-record coverage and class supports. If equal-record inference differs, this motivates a matched test of uniform record sampling during training. Inference weighting and training sampling answer different questions.
