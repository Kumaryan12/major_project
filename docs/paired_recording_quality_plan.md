# Signal quality and timing in paired PTB recordings

This read-only diagnostic replays the same 79 dated patient pairs and 256 matched beat draws from the frozen measured-XYZ ResNet. It tests whether later-minus-earliest accuracy differences track recording-quality proxies or timing. No models are fitted. The original beat crops, class labels, trained models and predictions define the inputs. [Matched beat-count result](../results/matched_recording_beats_v1/REPORT.md) · [PTB acquisition specification](https://physionet.org/content/ptbdb/1.0.0/)

Calculate the following measures from the physical and stored digital XYZ data without using predictions or labels. Use all beats when making complete-record transforms, then summarize the same sampled beats on both sides of each patient pair.

- **Baseline drift.** Apply a fixed fourth-order 0.5 Hz low-pass Butterworth filter forward and backward on each full raw axis. Within each cached R window, take the Euclidean norm of the three lead-specific peak-to-peak values. This is a low-frequency amplitude proxy in mV.
- **ADC rail hits.** Count sampled windows with at least one sample at a 16-bit ADC rail in any measured lead. Check declared digital format and gain. Report complete-record hits as a coverage check. Handle the WFDB invalid code explicitly. This check cannot identify analog clipping below the digital rail.
- **Cached R disagreement.** Reapply the original detector and parameters to raw XYZ and count sampled cached R positions more than 40 ms from the nearest raw detection. Neither detection is independently annotated. Denoising sensitivity and morphology can both affect disagreement.
- **Secondary recording checks.** Use centered relative raw-to-denoised change from the existing signal audit. Flag preceding cached RR intervals outside 300–2,000 ms, with the first cached beat missing for this measure. These flags include physiological variability.

For each measure, average the 256 matched draw means within each patient. Report earliest and later medians, paired mean change with a class-stratified 95% percentile interval, and the number of pairs with higher, lower or equal later values. The loss outcome is patient-level later-minus-earliest fraction of draws that predict the original class. The primary associations are the Spearman correlations of that outcome with the decreases in baseline drift and cached R disagreement. Report the association with each secondary measure and with days between the two recordings. Report the association with elapsed days from documented infarct to earliest recording only for pairs with the same documented infarct date on both recordings and a nonnegative earliest offset. These dates describe archived fields. Use 5,000 patient-bootstrap draws with seed 42. For correlations, take percentiles across draws that support finite ranks. Intervals are descriptive and class-stratified, without a covariate or causal adjustment. Provide per-class sample sizes and accuracy changes for context. Use the mean correct-class probability difference as a companion outcome for the two primary associations.

A quality-related change is a candidate for a future controlled intervention. Rare flags or wide intervals leave uncertainty about the contribution of recording quality. Relative visit dates alone cannot distinguish changes in injury, treatment, acquisition or annotation. Keep the existing blinded packet private. Publish aggregate output only. An independently completed clinical review remains a separate source of evidence. [Reviewer packet protocol](matched_recording_beats_plan.md)
