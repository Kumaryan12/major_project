For each of ten outer folds, split the paired patients from the outer-training set into three stratified cross-fitting partitions. Fit a separate teacher on the later records of the other two partitions, for eight fixed epochs with the same compact ResNet and class/patient-balanced sampling. No teacher sees the student outer-test patients or its own target patients. A teacher supplies the mean six-way probability vector over all later-record beats of each target. Teachers use a fixed seed scheme and are shared across student seeds. No selection or stopping uses the teacher query labels.

Train three student arms for each fold and seed 42, 123 and 2026. Match initial weights, all sampled rows, train-only normalization, dropout, learning rate, optimizer and eight epochs. Use 2,048 beat draws per epoch with replacement, balancing classes and patients within class. Each student's one-record prediction averages every beat of the selected record.

- **Supervised.** Ordinary per-beat cross-entropy.
- **Paired.** Add KL divergence to the true cross-fitted patient teacher target for paired training patients.
- **Shuffled.** Apply the same loss and pairing mask, with teacher vectors reassigned among training patients of each original class via a seeded derangement. Preserve the exact vector set in each class. Cross-fit target generation uses the true source patient's index before remapping.

Use temperature 2 with the usual squared-temperature multiplier. Soften the pooled teacher probabilities by a power of 1/2 and renormalize. Weight the KL term by 1 and average it over the full batch, with zero term for unpaired patients. None of these settings are selected using outer results.

The 30 teachers and 90 students require saved scopes, closed checkpoints and independent prediction replay. Recreate teacher partitions, student beat draws and the shuffle during replay.
